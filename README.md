# אורי אסא · בניית אתרים לעסקים

האתר האישי של העסק. אתר סטטי רב-עמודי, בלי שלב בנייה ובלי תלויות.

**כתובת חיה:** https://orikiassa.github.io

## מבנה

| קובץ | תפקיד |
|---|---|
| `index.html` | דף הבית - מסך השאלה, שלוש התשובות, תהליך, תצוגה מקדימה של תיק העבודות |
| `about.html` | אודות + הראיות למה עסק קטן צריך אתר |
| `work.html` | תיק עבודות - שלוש הדגמות |
| `contact.html` | יצירת קשר |
| `config.js` | **מקור האמת היחיד לתוכן.** כל הטקסטים, הטלפון והצבעים כאן |
| `style.css` | עיצוב מלא |
| `script.js` | רינדור מה-config, ניווט, חשיפה בגלילה, טופס → וואטסאפ |
| `assets/` | צילומי מסך של ההדגמות |
| `work/` | שלוש ההדגמות החיות (אתרים מלאים, מוגשים מתוך אותו ריפו) |

## עדכון תוכן

כמעט כל שינוי טקסט נעשה ב-`config.js` בלבד ומתעדכן בכל העמודים.
לשינוי מספר טלפון: `business.phone`, `business.phoneDisplay` ו-`business.whatsapp` (בפורמט בינלאומי, בלי `+`).

## הדגמות ב-`work/`

`tahana-burger-fire`, `liba-pilates` ו-`hakise-barbershop` הם **דוגמאות עבודה** שנבנו מיוזמתי - העסקים שבהם בדיוניים ואינם לקוחות אמיתיים.
זה מסומן במפורש בכל מקום שבו הם מוצגים.

## הרצה מקומית

```bash
python3 -m http.server 8777
# http://localhost:8777
```

## פרסום

GitHub Pages מהענף `main`, תיקיית השורש. `.nojekyll` מבטל את עיבוד Jekyll.
