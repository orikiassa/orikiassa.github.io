# דוגמת עבודה: הכיסא · מספרה קלאסית

**זו הדגמה, לא אתר של לקוח אמיתי.** "הכיסא" הוא עסק בדיוני, וכל הטקסטים, פרטי הקשר, המחירים והתמונות נכתבו ונבחרו לצורך ההדגמה בלבד.

שישה עמודי HTML נפרדים עם ניווט אמיתי - בית, שירותים ומחירים, הספרים, גלריה, הגעה וקביעת תור.

- כיוון עיצובי "הכיסאות": לבן אריחים, פחם, בורדו ופליז. הגיבור של דף הבית הוא פס נגלל של כרטיסי ספרים ("בחרו כיסא"), והמחירון מעוצב כשלט קיר.
- `config.js` הוא מקור האמת היחיד לתוכן: הספרים, המחירון, שעות הפתיחה, הגלריה והצבעים.
- **קביעת תור:** עמוד `book.html` מדגים בחירה של ספר, שירות, יום ושעה. השעות הפנויות מחושבות בדפדפן לצורך ההדגמה בלבד. באתר של לקוח אמיתי ממלאים את `booking.url` ב-`config.js` בקישור למערכת התורים הקיימת של המספרה, והכפתור בסוף מעביר אליה.
- התמונות הן תמונות סטוק מ-Pexels.
- צמדי הצבעים נבדקו מול WCAG AA.

הרצה מקומית: `python3 -m http.server 8000`
