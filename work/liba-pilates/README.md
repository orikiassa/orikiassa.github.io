# דוגמת עבודה: ליבה · סטודיו פילאטיס

**זו הדגמה, לא אתר של לקוח אמיתי.** "ליבה" הוא עסק בדיוני, וכל הטקסטים, פרטי הקשר, המחירים והתמונות נכתבו ונבחרו לצורך ההדגמה בלבד.

בניתי את האתר הזה מיוזמתי כדי להראות איך נראה אתר מלא לסטודיו פילאטיס קטן: שישה עמודי HTML נפרדים עם ניווט אמיתי - בית, שיעורים, מערכת שעות, מחירון, אודות ויצירת קשר.

- כיוון עיצובי: עצם, פחם ושזיף אחד - סטודיו שמוכר קרבה ולא עוצמה, ולכן האתר שקט והתנועה מרוסנת.
- `config.js` הוא מקור האמת היחיד לתוכן: השיעורים, מערכת השעות, המחירון והצבעים. `script.js` ממלא ממנו את כל העמודים.
- התמונות הן תמונות סטוק מ-Pexels.
- צמדי הצבעים נבדקו מול WCAG AA.

הרצה מקומית: `python3 -m http.server 8000`
