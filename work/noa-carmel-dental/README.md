# דמו: ד״ר נועה כרמל - מרפאת שיניים

דמו רב-עמודי למרפאת שיניים פרטית, בכיוון עיצובי "רוגע קליני" - דרגת תנועה א' (מרוסן), בהתאם ל-`design-standards.md` בריפו `client-web-templates`.

## מבנה

חמישה עמודי HTML נפרדים עם ניווט אמיתי ביניהם: `index.html` (בית), `about.html` (אודות + צוות), `services.html` (כל הטיפולים), `gallery.html` (גלריה עם לייטבוקס), `contact.html` (קביעת תור, שעות ומפה).

- `style.css` - עיצוב, כולל טוקנים של `design-standards.md` (סקאלת גופן/מרווח/letter-spacing מותאם לעברית, עקומות תנועה, פינות וצללים).
- `script.js` - ממלא את כל התוכן בכל העמודים מתוך `config.js`, כולל תפריט המבורגר בנייד, לייטבוקס גלריה, וחשיפת כרטיסי טיפולים בגלילה (fade + טרנספורם, פעם אחת).
- `config.js` - **הקובץ היחיד שצריך לערוך** כדי להתאים לעסק אחר.

## הרצה מקומית

```bash
python3 -m http.server 8000
```
ואז גשו ל-`http://localhost:8000/index.html` ונווטו בין העמודים דרך התפריט.

## הערה על תמונות

כל התמונות (הירו, אודות, גלריה) הן תמונות סטוק זמניות מ-Pexels שאומתו בפועל (200 + content-type תקין). **יש להחליף אותן בתמונות אמיתיות של המרפאה** לפני שליחה סופית ללקוח.
