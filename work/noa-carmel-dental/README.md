# דוגמת עבודה: מרפאת שיניים

**זו הדגמה, לא אתר של לקוח אמיתי.** "ד״ר נועה כרמל" הוא עסק בדיוני, וכל הטקסטים, פרטי הקשר והתמונות נכתבו ונבחרו לצורך ההדגמה בלבד.

בניתי את האתר הזה מיוזמתי כדי להראות איך נראה אתר מלא למרפאת שיניים פרטית: חמישה עמודי HTML נפרדים עם ניווט אמיתי - בית, אודות, טיפולים, גלריה ויצירת קשר.

- כיוון עיצובי: "רוגע קליני" - קהל היעד מגיע עם חשש, ולכן הפלטה רגועה והתנועה מרוסנת.
- `config.js` הוא מקור האמת היחיד לתוכן; `script.js` ממלא ממנו את כל העמודים.
- התמונות הן תמונות סטוק מ-Pexels.
- צמדי הצבעים נבדקו מול WCAG AA.

הרצה מקומית: `python3 -m http.server 8000`
