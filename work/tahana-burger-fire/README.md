# דוגמת עבודה: טחנה · בורגר בר

**זו הדגמה, לא אתר של לקוח אמיתי.** "טחנה" הוא עסק בדיוני, וכל הטקסטים, פרטי הקשר, המחירים בתפריט והתמונות נכתבו ונבחרו לצורך ההדגמה בלבד.

בניתי את האתר הזה מיוזמתי כדי להראות איך נראה אתר מלא לבורגר בר: חמישה עמודי HTML נפרדים עם ניווט אמיתי - בית, תפריט, הבשר, גלריה וביקור.

- כיוון עיצובי: פחם וגחלים - רקע כהה, צבע חם אחד שנושא את כל ההדגשות, וטיפוגרפיה גדולה במקום קישוטים.
- `config.js` הוא מקור האמת היחיד לתוכן: שם העסק, התפריט, השעות והצבעים. `script.js` ממלא ממנו את כל העמודים.
- התמונות הן תמונות סטוק מ-Pexels.
- צמדי הצבעים נבדקו מול WCAG AA.

הרצה מקומית: `python3 -m http.server 8000`
