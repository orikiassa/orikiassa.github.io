# דוגמת עבודה: מוסך

**זו הדגמה, לא אתר של לקוח אמיתי.** "מוסך תמיר" הוא עסק בדיוני, וכל הטקסטים, פרטי הקשר והתמונות נכתבו ונבחרו לצורך ההדגמה בלבד.

בניתי את האתר הזה מיוזמתי כדי להראות איך נראה אתר לעסק שירות טכני, שאליו הלקוח מגיע בלחץ ומחפש קודם כול טלפון: חמישה עמודי HTML נפרדים - בית, אודות, שירותים, גלריה ויצירת קשר.

- הטלפון גלוי בכל עמוד, ויש כפתור חיוג צף בנייד.
- סרגל אמון (ותק, אחריות, הסמכה) במקום סיסמאות שיווקיות.
- `config.js` הוא מקור האמת היחיד לתוכן; `script.js` ממלא ממנו את כל העמודים.
- התמונות הן תמונות סטוק מ-Pexels.

הרצה מקומית: `python3 -m http.server 8000`
