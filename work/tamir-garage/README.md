# דמו: מוסך תמיר

דמו רב-עמודי לעסק שירות טכני (מוסך), בכיוון עיצובי "פלדה ונחושת" - דרגת תנועה א' (מרוסן), בהתאם ל-`design-standards.md` בריפו `client-web-templates`.

## מבנה

חמישה עמודי HTML נפרדים עם ניווט אמיתי ביניהם: `index.html` (בית), `about.html` (אודות), `services.html` (כל השירותים), `gallery.html` (תיק עבודות עם לייטבוקס), `contact.html` (יצירת קשר, שעות ומפה).

- `style.css` - עיצוב, כולל טוקנים של `design-standards.md` (סקאלת גופן/מרווח/letter-spacing מותאם לעברית, עקומות תנועה, פינות וצללים).
- `script.js` - ממלא את כל התוכן בכל העמודים מתוך `config.js`, כולל תפריט המבורגר בנייד, לייטבוקס גלריה, וחשיפת כרטיסים בגלילה (fade + טרנספורם, פעם אחת).
- `config.js` - **הקובץ היחיד שצריך לערוך** כדי להתאים לעסק אחר.

## הרצה מקומית

```bash
python3 -m http.server 8000
```
ואז גשו ל-`http://localhost:8000/index.html` ונווטו בין העמודים דרך התפריט.

## הערה על תמונות

כל התמונות (הירו, אודות, גלריה) הן תמונות סטוק זמניות מ-Pexels שאומתו בפועל (200 + content-type תקין). **יש להחליף אותן בתמונות אמיתיות של מוסך תמיר** לפני שליחה סופית ללקוח.
